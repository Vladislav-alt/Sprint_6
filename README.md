Проект автоматизации тестирования для "Яндекс.Самокат"
Этот проект содержит автоматизированные тесты для учебного сервиса «Яндекс.Самокат».

 Функциональность
Проект покрывает следующие тестовые сценарии:

1. Тесты FAQ (Вопросы о важном)
Проверка раскрытия текста ответов при клике на каждый вопрос

Параметризованные тесты с проверкой соответствия вопрос-ответ

2. Тесты заказа самоката
Полный флоу позитивного сценария заказа

Два набора тестовых данных

Тестирование через обе кнопки "Заказать" (верхняя и нижняя)

Заполнение всех полей формы и подтверждение заказа

3. Тесты редиректов
Проверка перехода на главную страницу через логотип Самоката

Проверка перехода на Дзен через логотип Яндекса



 Установка и запуск
1. Клонирование и настройка
bash
git clone <repository-url>
cd Sprint_6
2. Установка зависимостей
bash
pip install -r requirements.txt
3. Запуск тестов
Все тесты:

bash
pytest tests/ -v
Только тесты FAQ:

bash
pytest tests/test_main_page.py::TestFAQ -v
Только тесты заказа:

bash
pytest tests/test_order_flow.py -v
Только тесты редиректов:

bash
pytest tests/test_main_page.py::TestLogoRedirects -v
4. Генерация Allure-отчета
bash
# Запуск тестов с сохранением результатов
pytest tests/ --alluredir=allure-results

# Генерация и просмотр отчета
allure serve allure-results/
